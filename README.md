# Spo0kNet

**Spo0kNet** is a personal Discord assistant built for speed, control, and simplicity.
Designed to help you manage conversations and stay organized without breaking your flow.

Features:
• ⚡ Instant reply commands (/offline, /busy, /brb)
• 📩 Send quick DMs through commands
• ⏱️ Reminders and follow-ups so you don’t forget messages
• 🔎 Mention tracking (see who tried to reach you)
• 🎭 Custom reply styles (blunt, chill, formal)
• 🧠 Utility tools (timestamps, formatting, quick text fixes)

Built to feel like *you*, just faster.
